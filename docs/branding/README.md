| File | What it is |

The app and menu icons are the same logo at 512 / 256 / 128 / 64 px in `packaging/icons/`.

## About the sticker
The colour logo is detailed (foil texture, glow, fine hieroglyphs), which cannot be cut or printed in one colour. `code-sticker.svg` is
therefore a **simplified redraw** made for this project (`scripts/make_sticker.py`): winged crest, crown, **CODE** with the ankh as the O,
and a chevron below. Gaps between shapes are wide enough to cut cleanly. Ask the print shop for "black, cut-out / transfer, 10 cm wide or larger".

## Rights - please read
The colour logo and the intro video were **made with AI tools** and supplied by the project owner. In many countries (for example the USA)
purely AI-generated artwork **cannot be copyrighted** and it may be difficult to register as a trademark, so do not count on exclusive rights
to it. They contain no third-party logos. If the name matters commercially, have a designer redraw it and check the name "Code" is free for your use
(Microsoft's Visual Studio Code is also commonly called "Code").
